# Rithik Chauhan — Red Team Portfolio (reference-style v3)

Static site: `index.html`, `style.css`, `script.js`, `assets/`. No build step.

Preview: `python3 -m http.server 8000` → http://localhost:8000

Deploy (GitHub Pages): copy all files to the repo root, keep `assets/`.

Features: preloader, glitch name, scroll-driven 5-layer assessment pipeline, stat counters, tickers,
typed terminal snippets, interactive shell (try `help`, `flag`, `theme ice`), 3 colour variants
(footer dock), certificate vault modal, reduced-motion support.
Contact form composes your message, copies it to the clipboard and opens LinkedIn (no email published).
